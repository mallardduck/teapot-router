teapot-router

Routes, gently steeped. Named routes, query dispatch, and S3 action context, built on chi.

Read the chi docs first. teapot-router is a thin layer over chi, not a replacement. Routing basics, URL parameters, middleware, and the http.Handler model all work the same way here. The chi README, the chi API docs, and go-chi/docs are the primary references. These pages cover only what teapot-router adds.

Install

go get github.com/mallardduck/teapot-router

A taste

Register routes with names, then build URLs from those names:

r := teapot.New()

r.GET("/users", listUsers).Name("users.index")
r.GET("/users/{id}", showUser).Name("users.show")

path := r.MustURL("users.show", "id", "42") // "/users/42"

Route the same path to different handlers based on query parameters, the way S3 does:

r.Dispatch("GET", "/{bucket}", func(d *teapot.DispatchBuilder, m teapot.Matchers) {
    d.DefaultFunc(listObjects).Name("bucket.list").Action("s3:ListBucket")
    d.When(m.QueryExists("acl")).DoFunc(getBucketAcl).Name("bucket.acl").Action("s3:GetBucketAcl")
})
