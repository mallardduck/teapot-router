Migrating to v1

Changes since v0.15.2 that affect existing code. Each entry says what breaks and how to update.

Breaking changes

Resource takes a controller and options

ResourceHandlers, ResourceHandlerBuilder, and NewResourceHandlers are removed.

// before
r.Resource("photos", "/photos", "photo", teapot.ResourceHandlers{
    Index: http.HandlerFunc(listPhotos),
    Show:  http.HandlerFunc(showPhoto),
})

// after
type PhotoController struct{}

func (PhotoController) Index(w http.ResponseWriter, r *http.Request) { listPhotos(w, r) }
func (PhotoController) Show(w http.ResponseWriter, r *http.Request)  { showPhoto(w, r) }

r.Resource("photos", PhotoController{})
  • The path defaults to / plus the name. Use teapot.Path to change it.
  • The parameter defaults to the singular of the name. Use teapot.Param to change it.
  • UpdateMethod is gone. Update still registers both PUT and PATCH. To give them different handlers, implement Replace (PUT) and Patch (PATCH) instead.
  • Head is now an optional method on the controller. Implement it to register an explicit HEAD route. Without it, HEAD requests still fall back to GET. See HEAD fallback.
  • StoreVerb must be POST or PUT. Other values panic at registration.

Router.Func() is removed

// before
r.Func().GET("/users", listUsers)

// after
r.GET("/users", http.HandlerFunc(listUsers))
// or
r.HandleFunc("GET", "/users", listUsers)

dispatch handlers take http.Handler

Builder.Default and Route.Do now take http.Handler, matching teapot.Dispatch. For a function, use DefaultFunc and DoFunc:

// before
b.Default(listV1)
b.When(dispatch.QueryExists("acl")).Do(getACL)

// after
b.DefaultFunc(listV1)
b.When(dispatch.QueryExists("acl")).DoFunc(getACL)

A router or any other http.Handler can now be passed directly, for example Do(vhostRouter).

Renamed: FuncDefault and FuncDo

These are now DefaultFunc and DoFunc. This affects release-candidate users (v0.16.0-rc.1).

Behavior changes

  • HEAD fallback. A HEAD request with no HEAD route is served by the GET route for the same path. It used to return 405. An explicit HEAD route still wins.
  • Host matching. A trailing dot on a host (bucket.example.com.) is ignored, and matching is case-insensitive. Generated URLs are lowercase and never carry a trailing dot.
  • SubdomainURL adds a leading slash when the path lacks one.

Additions

  • Router.RegisterDebugRoute(path, name) registers the route listing endpoint.
  • Matchers.HostHasSubdomain(domain) for Dispatch callbacks.
  • Router.HandleFunc(method, pattern, fn), plus DefaultFunc and DoFunc on dispatch.
  • The HTML route table is sortable by method, pattern, and name.
  • The Only, Except, Middleware, Path, Param, Names, and StoreVerb options for Resource.

Dependencies

New: github.com/jinzhu/inflection, used for the default Resource parameter name.
