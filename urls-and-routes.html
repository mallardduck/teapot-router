URLs & route listing

Build absolute URLs from named routes, and list the routes your router serves.

Absolute URLs

r.MustURL returns a path. The urlbuilder package turns that into a full URL, using the request for scheme detection and a canonical domain you set:

import "github.com/mallardduck/teapot-router/pkg/urlbuilder"

urls := urlbuilder.New("s3.example.com")

path := r.MustURL("object.get", "bucket", "photos", "key", "2024/vacation.jpg")
full := urls.BuildURL(r, path)
// "https://s3.example.com/photos/2024/vacation.jpg"

bucket := urls.BucketURL(r, "photos")              // bucket-level URL
object := urls.ObjectURL(r, "photos", "2024/a.jpg") // object-level URL

// SubdomainURL returns false when the label cannot form a valid subdomain.
sub, ok := urls.SubdomainURL("photos", "/2024/a.jpg")
// "https://photos.s3.example.com/2024/a.jpg", true
  • The scheme is https when the request is TLS or X-Forwarded-Proto says so. Otherwise it is http.
  • Generated URLs are lowercase and never end in a trailing dot.

Listing routes

Every router can report its routes:

for _, route := range r.Routes() {
    fmt.Printf("%s %s -> %s (%s)\n", route.Method, route.Pattern, route.Name, route.Action)
}

// Across several routers, including mounted sub-routers
all := teapot.AggregateRoutes(r, admin)

Debug endpoint

Register an HTTP endpoint that lists routes as JSON or HTML. Put it behind a debug flag, not in production:

if debug {
    r.RegisterDebugRoute("/.internal/routes", "debug.routes")
}

Formatters

Write a route list in table, JSON, or compact form to any io.Writer:

teapot.FormatRoutesTable(os.Stdout, routes)
teapot.FormatRoutesJSON(os.Stdout, routes)
teapot.FormatRoutesCompact(os.Stdout, routes)

Use teapot.FilterRoutes to narrow a list before formatting. Use teapot.NewListRoutesHandler when you need the handler outside RegisterDebugRoute.

Try it

The repository has a runnable example, a mock S3 route table, in examples/routes-cli:

go run ./examples/routes-cli           # table
go run ./examples/routes-cli --json    # JSON
go run ./examples/routes-cli --compact # compact

Standalone dispatch

The dispatch package routes by query, header, and host without teapot. It is an http.Handler, so it works with the standard library, chi, or any other router:

import "github.com/mallardduck/teapot-router/pkg/dispatch"

d := dispatch.New(func(b *dispatch.Builder) {
    b.DefaultFunc(listHandler)
    b.When(dispatch.QueryEquals("format", "xml")).DoFunc(xmlHandler)
    b.When(dispatch.QueryExists("search")).DoFunc(searchHandler)
})

http.Handle("/api/items", d)
